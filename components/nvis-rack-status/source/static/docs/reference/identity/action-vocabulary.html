Action vocabulary#

Reference — a description of the machinery. Look things up here.

Every action the product declares, which is what a policy’s actions field may name. Generated from the live registry — a route without a declaration cannot appear here, and the build gate in backend/tests/test_action_coverage.py fails if one exists.

206 actions across 59 services: 68 reads and 138 mutations.

A read-only role is ["*:read", "*:list"] — the two read verbs — rather than an enumeration of the reads below.

Each service’s description is the first line of the module that owns it, so it is written and reviewed in the same commit as the behaviour. Identified by is the request keys a policy’s target is read from; case-folded matters because a deny written in the other case does not match.
