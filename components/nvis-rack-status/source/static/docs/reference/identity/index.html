Identity and authorization#

Reference — a description of the machinery. Look things up here.

Who a caller is, what they may do, and how that is written down.

Note

Two of the references here are generated from the code and are authoritative: docs/ACTION_VOCABULARY.md lists every action the product declares, and docs/RESOURCE_MODEL.md every resource type. The running product serves live copies at GET /api/policies/vocabulary and GET /api/policies/schema, so an operator writing a policy does not need the repository.

These pages describe the grammar and semantics around those lists rather than restating them — a hand-copied list of 177 action names would be wrong within a week.
